# Research Pattern: Geopolitical Analysis Article (2026-06-13)

## Task Flow
1. User asks about current events (美伊和谈)
2. Web research via Google News RSS → gather headlines, dates, sources
3. Deep dive into specific subtopics (冻结资产, Hormuz tolls) via more RSS queries
4. Cross-reference with knowledge base (Zoltan Pozsar articles in raw/inbox/)
5. Synthesize into analytical article with personal voice
6. Iterate on style based on user feedback (multiple rounds of refinement)

## Style Iteration Rounds
1. First draft: Too formal/news-like → user asked for personal, conversational tone
2. Second draft: Still had format-heavy citations → user asked to simplify
3. Third draft: Too many direct quotes from Pozsar → user asked to paraphrase
4. Structure fix: Sections felt disconnected → added transition sentences
5. Depth fix: "时代终结" section too surface-level → rewrote with "五根支柱" framework
6. Prediction removal: "接下来会发生什么" section removed → user said predictions "淡而无味" weaken articles. Analysis should end at peak insight or a strong metaphor, not uncertain forecasting
7. Depth reinforcement: User said "你还是没明白" about五根支柱 → needed complete causal chains (e.g., 运输成本→保费→绕道→价格地板), not surface statements. Each analytical point must have its full logical chain visible

## Key Lesson: Depth vs Surface
The most persistent correction was about analytical depth. The user's standard is their OWN writing — which has:
- Complete causal chains (not just "X is happening" but "X → Y → Z → consequence")
- Structural logic (identifying pillars/frameworks, not just listing events)
- The "why" behind every claim (not just "Pakistan is mediator" but "Pakistan is mediator because it has interests on both sides")

When the user says "论述不够" or "你还是没明白", it means the analysis needs more logical connective tissue, not more words.
