# BTC三重风险文章 — 写作范例

## 背景
2026-06-04 用户要求基于终端数据分析BTC风险并写成公众号文章。
初版被用户否定："太机械了，给机器看的，不是给人看的。"
重写后通过。

## 失败版 vs 通过版对比

### 失败版开头
```
## 引言
2020年以来，比特币从一个边缘另类资产成长为市值万亿美元的金融符号。但当我们用终端数据逐层拆解 BTC 的定价逻辑时...
```
→ 问题：学术腔，没有钩子，读者3秒内会划走

### 通过版开头
```
2026年6月2日，纳斯达克100涨了0.5%，黄金基本持平，比特币却暴跌了6.5%。
这不是一次偶然的闪崩。如果你把时间拉长到2026年3月，你会发现一个令人不安的规律...
```
→ 好在哪：具体数字+反常识对比+悬念

### 失败版结构
```
第一重风险：流动性退潮
1.1 流动性驱动力的切换
1.2 终端数据验证
1.3 2025年Q3 的致命转折
```
→ 问题：编号+小标题=论文，不是文章

### 通过版结构
```
第一个引擎熄火：钱从哪里来？
→ 讲水龙头的故事
第二个引擎熄火：没人再讲你的故事了？
→ 讲叙事的崩塌
第三个引擎熄火：通胀把你钉在了十字架上
→ 讲通胀陷阱
```
→ 好在哪：比喻串联，有情绪，有节奏

### 失败版结尾
```
结论：BTC 在通胀陷阱中被三面夹击——流动性、叙事、实际利率三个方向同时恶化。
```

### 通过版结尾
```
有人说比特币是"数字黄金"。但从数据来看，它更像是黄金的影子——当光线充足的时候，
影子很长、很清晰；当光线消失的时候，影子也跟着消失了。
2026年的比特币，正处在一个三重光线同时熄灭的时刻...
当你把所有支撑它的逻辑一层层剥开之后，底下什么都没有。这才是真正的风险。
```
→ 好在哪：比喻收束+金句+开放性思考

## 关键写作原则
1. 钩子用具体数字，不用抽象描述
2. 类比比术语更有传播力
3. 数据是论据，不是主角
4. 结尾要让人记住一句话
5. 段落短，适合手机阅读
